# Security Policy

## Supported Versions

| Version | Filament | Supported |
|---------|----------|-----------|
| 5.x | 5.x | Yes, security fixes and bug fixes |
| 1.x (`v3` branch) | 3.x | Security fixes only |
| < 1.0 | — | No |

Security fixes are released as a patch version on every supported line. Please upgrade to the latest patch release of your line.

## Reporting a Vulnerability

**Please do not open a public issue, discussion or pull request for security problems.**

Report privately through one of these channels:

1. **GitHub private vulnerability reporting** (preferred): [Report a vulnerability](https://github.com/tomatophp/filament-ecommerce/security/advisories/new) from the repository's **Security** tab.
2. **Email**: [engfadymondy@gmail.com](mailto:engfadymondy@gmail.com) with the subject `SECURITY: filament-ecommerce`.

Please include the affected version or commit, a description of the impact, and steps or a proof of concept to reproduce it.

## What to Expect

| Step | Target time |
|------|-------------|
| Acknowledge your report | within 3 business days |
| Confirm the issue and share an initial assessment | within 7 days |
| Release a fix for critical / high severity issues | within 30 days |
| Release a fix for medium / low severity issues | within 90 days |

We publish a GitHub Security Advisory once the fixed version is available, request a CVE when appropriate, and credit you as the reporter unless you prefer to stay anonymous. Please keep the details private until the advisory is published. We follow a 90-day coordinated disclosure window by default.

See also the [TomatoPHP organization security policy](https://github.com/tomatophp/.github/blob/main/SECURITY.md).
